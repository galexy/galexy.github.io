Last week Claude Code released an update to the Todo tools and now support
[Tasks](https://x.com/trq212/status/2014480496013803643) that are stored in the file system and can be used to corrindate 
across subagents and over multiple sessions. This is very similar to how
I've been using [story/design markdown files with task lists](https://flatmap.io/snippets/2026-01-28-coding-agents-vs-meta-programming/#:~:text=My%20style%20is%20very%20similar%20to%20the%20scoped%20SDLC%20that%20Steve%20Jones%20wrote%20about.%20I%20spent%20most%20of%20my%20interaction%20with%20Claude%20via%20a%20markdown%20file%20that%20we%20edited%20together%20along%20with%20a%20back%20and%20forth%20conversation%20discussing%20the%20design%20document.) 
that are checked in for each feature I'm working on.

It's crazy to see how Anthropic is so quickly incorporating these features
from the community.
