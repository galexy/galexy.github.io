The CSS `:has()` pseudo-class is like a "parent selector"! You can style elements based on what they contain.

```css
/* Style a card that has an image */
.card:has(img) {
  padding: 0;
}

/* Style a form with invalid inputs */
form:has(input:invalid) {
  border-color: red;
}
```

Game-changer for styling components without JavaScript!
