JavaScript arrays have an `.at()` method that supports negative indices! This makes it easy to access elements from the end of an array without calculating the length.

```javascript
const arr = [1, 2, 3, 4, 5];
arr.at(-1);  // 5 (last element)
arr.at(-2);  // 4 (second to last)
```

Much cleaner than `arr[arr.length - 1]`!
