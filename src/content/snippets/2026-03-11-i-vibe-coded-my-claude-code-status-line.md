I recently started using team agents and wanted to see how much context window usage each agent was consuming. I merely asked Claude Code to update the status and did it and the update was done in real time. I wrote a bash script. I asked it convert it into a [python script instead](https://github.com/galexy/edgar-diff/blob/599682b3eb357ee83461b5cc9852b0ed610fe35a/.claude/scripts/claude-context-bar.py). I then asked it add more things and even use emojis. It's so crazy that the code that was being generated was used to update the environment the coding tool was in. Absolutely wild. 🤯
